## Voice Cloning: How NeuTTS Air Works in Your Code

### The Question: "How do you generate fake audio?"

### IMPORTANT: This is REFERENCE-BASED synthesis, not simple text-to-speech!

### Step-by-Step Process:

**Step 1: Load the TTS Model**
```python
from neuttsair.neutts import NeuTTSAir

# Initialize NeuTTS Air
tts_model = NeuTTSAir()
# Downloads ~10GB model files from Hugging Face
# Loads transformer + vocoder into memory
```

**What happens internally:**
- Downloads pre-trained weights
- Initializes components for reference-based synthesis
- Loads Perth watermark embedder

---

**Step 2: Select TIMIT Reference Speaker**
```python
# Pick a TIMIT speaker to clone
target_audio_path = "TIMIT/TRAIN/DR1/FCJF0/SA1.WAV"
```

**What you're selecting:**
- FCJF0: Female speaker from dialect region 1
- SA1.WAV: Audio of her saying "She had your dark suit..."
- This is the voice you want to clone

---

**Step 3: Load Reference Transcript**
```python
# TIMIT provides .TXT files with transcripts
ref_txt_path = Path(target_audio_path).with_suffix('.TXT')

if ref_txt_path.exists():
    with open(ref_txt_path, 'r') as f:
        content = f.read().strip()
        # Example: "0 46797 She had your dark suit in greasy wash water all year"
        parts = content.split()
        ref_text = ' '.join(parts[2:])  # Skip timing info
        # Result: "She had your dark suit in greasy wash water all year"
else:
    ref_text = source_text  # Fallback if no transcript
```

**What ref_text contains:**
- The actual words spoken in the reference audio
- Used by NeuTTS Air for alignment and better synthesis quality
- NOT generated by Whisper - comes directly from TIMIT .TXT files

---

**Step 4: Encode Reference Audio**
```python
# Capture the speaker's voice characteristics
ref_codes = self.tts_model.encode_reference(str(target_audio_path))

# ref_codes contains:
# - Pitch patterns
# - Tone quality
# - Speaking rate
# - Accent/dialect
# - Voice timbre
# Compressed into a tensor (shape logged in code)
```

**What `encode_reference()` does:**
```
FCJF0/SA1.WAV (audio file)
  ↓
[Analyze audio characteristics]
  - Extract prosody (pitch contour, rhythm)
  - Extract timbre (voice quality)
  - Extract accent/speaking style
  ↓
ref_codes (tensor representing voice)
```

**Key point:** This creates a "voice fingerprint" for the speaker.

---

**Step 5: Choose Text to Synthesize**
```python
source_text = "The quick brown fox jumps over the lazy dog"
```

**CRITICAL DIFFERENCE:**
- `source_text`: What you want the clone to say (NEW sentence!)
- `ref_text`: What the reference speaker actually said
- The speaker NEVER said source_text - you're making them "say" it!

---

**Step 6: Generate Cloned Audio**
```python
# Make FCJF0's voice say the NEW text
cloned_wav = self.tts_model.infer(
    source_text,  # "The quick brown fox..." (NEW!)
    ref_codes,    # FCJF0's voice characteristics
    ref_text      # "She had your dark suit..." (reference)
)

# Returns:
# - cloned_wav: numpy array of audio samples at 24kHz
# - Automatically includes Perth watermark
```

**What happens internally:**
```
source_text + ref_codes + ref_text
  ↓
[Text encoder]
  Process source_text with ref_codes conditioning
  ↓
[Attention mechanism]
  Align source_text phonemes with ref_text prosody
  ↓
[Decoder with voice characteristics]
  Generate mel-spectrogram in target speaker's voice
  ↓
[Perth Watermark Embedder]  ← Automatic!
  ↓
[Vocoder]
  Convert to waveform at 24kHz
  ↓
cloned_wav (FCJF0 saying "The quick brown fox...")
```

**Key point:** Perth watermark is embedded automatically during synthesis.

---

**Step 7: Save Audio File**
```python
import soundfile as sf

# Save as WAV file
sf.write('fake_audio.wav', cloned_wav, sample_rate=24000)
```

**What you get:**
- WAV file at 24kHz sample rate
- Duration: ~2-3 seconds (depends on source_text length)
- Voice sounds like FCJF0 (reference speaker)
- Content is source_text (NEW sentence she never said!)
- Embedded Perth watermark (invisible to you, detectable by analysis)

---

### Progressive Scaling: How You Generated 700 Samples

**The Problem:** Generating all 700 at once crashes (out of memory).

**Your Solution:** Progressive scaling
```python
batch_sizes = [5, 10, 20, 50, 100, 200, 400, 700]

for target in batch_sizes:
    for i in range(previous_count, target):
        # Generate one sample
        text = select_random_text()
        audio, sr = tts_model.synthesize(text)
        sf.write(f'fake_{i}.wav', audio, sr)

        # CRITICAL: Memory cleanup after each sample
        torch.cuda.empty_cache()
        gc.collect()

    print(f"Successfully generated {target} samples")
    # If this succeeds, continue to next batch
```

**Why this works:**
- Generates ONE sample at a time (sequential, not parallel)
- Memory cleanup prevents accumulation
- Progressive batches catch memory issues early
- Total time: 67.7 minutes for 700 samples (~5.8 seconds per sample)

**Interview Answer:**
> "I generate fake audio using NeuTTS Air with reference-based voice cloning. First, I select a TIMIT speaker (e.g., FCJF0) and load their audio file. I call `encode_reference()` to capture their voice characteristics into ref_codes. Then I call `infer()` with three parameters: new text to synthesize, the ref_codes, and the reference transcript from TIMIT's .TXT file. NeuTTS Air generates audio in that speaker's voice saying the new text, automatically embedding a Perth watermark. I use progressive scaling (5→10→20→700 samples) with sequential processing and memory cleanup between each sample. This takes 67.7 minutes total."

## CNN Detection: Input to Output Flow

### The Question: "Walk me through how your CNN processes an audio file to detect if it's fake."

### Step-by-Step Process:

**INPUT: Audio file (WAV)**
- File: `suspicious_audio.wav`
- Duration: ~3 seconds
- Sample rate: any (will be resampled)

---

**Step 1: Load Audio**
```python
import librosa

# Load and resample to 16kHz
audio, sr = librosa.load('suspicious_audio.wav', sr=16000)

# Now we have:
# audio: numpy array of samples (e.g., 48000 samples for 3 seconds)
# sr: 16000 Hz
```

**What happens:** Librosa reads WAV file and resamples to 16kHz if needed.

**Why 16kHz?** Nyquist theorem: 16kHz captures up to 8kHz frequency, which covers human speech (80-4000 Hz).

---

**Step 2: Extract Features (30 dimensions)**

**2a. Compute MFCCs**
```python
# Extract 13 MFCCs
mfccs = librosa.feature.mfcc(
    y=audio,
    sr=16000,
    n_mfcc=13,
    n_fft=1024,
    hop_length=512
)
# Shape: (13, time_frames)
# Example: (13, 94) for 3-second audio

# Compute statistics over time
mfcc_mean = np.mean(mfccs, axis=1)  # Shape: (13,)
mfcc_std = np.std(mfccs, axis=1)    # Shape: (13,)
```

**What this captures:**
- **MFCC mean**: Average spectral shape (vocal tract characteristics)
- **MFCC std**: Temporal variability (how much the sound changes over time)

**Example values:**
```
MFCC means:  [-150.2, 45.3, -12.1, 8.9, ..., 2.1]  # 13 values
MFCC stds:   [23.5, 12.1, 8.3, 5.2, ..., 1.8]      # 13 values
```

**Key insight:** Fake audio has LOWER std (TTS is too consistent).

---

**2b. Compute Spectral Features**
```python
# Spectral centroid
centroid = librosa.feature.spectral_centroid(y=audio, sr=16000)
centroid_mean = np.mean(centroid)  # Single value, e.g., 2341.5 Hz

# Spectral rolloff
rolloff = librosa.feature.spectral_rolloff(y=audio, sr=16000)
rolloff_mean = np.mean(rolloff)  # Single value, e.g., 4523.8 Hz

# Spectral bandwidth
bandwidth = librosa.feature.spectral_bandwidth(y=audio, sr=16000)
bandwidth_mean = np.mean(bandwidth)  # Single value, e.g., 1821.3 Hz

# Zero crossing rate
zcr = librosa.feature.zero_crossing_rate(y=audio)
zcr_mean = np.mean(zcr)  # Single value, e.g., 0.082
```

**What these capture:**
- **Centroid**: Brightness (fake audio often higher)
- **Rolloff**: Energy distribution (fake has unnatural spread)
- **Bandwidth**: Frequency spread (fake more uniform)
- **ZCR**: Noisiness (fake has lower ZCR, cleaner signal)

---

**2c. Combine All Features**
```python
# Concatenate into 30-D vector
features = np.concatenate([
    mfcc_mean,      # 13 values
    mfcc_std,       # 13 values
    [centroid_mean, rolloff_mean, bandwidth_mean, zcr_mean]  # 4 values
])
# Shape: (30,)

# Example:
# features = [-150.2, 45.3, ..., 23.5, 12.1, ..., 2341.5, 4523.8, 1821.3, 0.082]
```

---

**Step 3: Normalize Features**
```python
from sklearn.preprocessing import StandardScaler

# Fit on training data (done once during training)
scaler = StandardScaler()
scaler.fit(training_features)  # Learn mean and std from training set

# Transform the input
normalized = scaler.transform(features.reshape(1, -1))
# Shape: (1, 30)

# Each feature now has mean=0, std=1
```

**What this does:**
```
Before: [2341.5, 0.082, ...]  ← Different scales!
After:  [0.73, -1.2, ...]     ← Same scale (standardized)
```

**Why needed:** Neural networks work better when all inputs are on the same scale.

---

**Step 4: Feed to CNN**
```python
import torch

# Convert to tensor
input_tensor = torch.tensor(normalized, dtype=torch.float32)
# Shape: (1, 30)

# Reshape for Conv1D (add channel dimension)
input_tensor = input_tensor.unsqueeze(1)
# Shape: (1, 1, 30)
#        ↑  ↑  ↑
#    batch channel length

# Load trained model
model = OptimizedCNN()
model.load_state_dict(torch.load('cnn_model.pth'))
model.eval()  # Set to evaluation mode

# Forward pass
with torch.no_grad():  # No gradient computation (faster)
    logits = model(input_tensor)
    # Shape: (1, 2)
    # Example: logits = [[0.45, 3.21]]
```

---

**Step 5: CNN Internal Processing**

**What happens inside the model:**

```python
# Input: (1, 1, 30)

# Conv Block 1
x = conv1d_1(x)      # (1, 1, 30) → (1, 64, 30)
x = batch_norm_1(x)  # Normalize
x = relu(x)          # Activation
x = maxpool(x)       # (1, 64, 30) → (1, 64, 15)

# Conv Block 2
x = conv1d_2(x)      # (1, 64, 15) → (1, 128, 15)
x = batch_norm_2(x)
x = relu(x)
x = maxpool(x)       # (1, 128, 15) → (1, 128, 7)

# Conv Block 3
x = conv1d_3(x)      # (1, 128, 7) → (1, 256, 7)
x = batch_norm_3(x)
x = relu(x)
x = maxpool(x)       # (1, 256, 7) → (1, 256, 3)

# Flatten
x = flatten(x)       # (1, 256, 3) → (1, 768)

# Fully Connected Layers
x = fc1(x)           # (1, 768) → (1, 512)
x = relu(x)
x = dropout(x)       # Randomly zero 50% (only during training, skipped in eval)
x = fc2(x)           # (1, 512) → (1, 128)
x = relu(x)
x = dropout(x)
x = fc3(x)           # (1, 128) → (1, 2)

# Output: logits = (1, 2)
# Example: [[0.45, 3.21]]
#           ↑     ↑
#         real  fake
```

**What each layer learns:**
- **Conv1**: Basic patterns (MFCC spike, zero-crossing cluster)
- **Conv2**: Combined patterns (MFCC spike + low ZCR = voiced segment)
- **Conv3**: High-level patterns (unnatural prosody signature)
- **FC layers**: Holistic decision (combine all evidence → real or fake)

---

**Step 6: Convert Logits to Probabilities**
```python
import torch.nn.functional as F

# Apply softmax
probabilities = F.softmax(logits, dim=1)
# Shape: (1, 2)
# Example: [[0.091, 0.909]]
#           ↑     ↑
#       P(real) P(fake)

# Extract values
p_real = probabilities[0, 0].item()  # 0.091 (9.1%)
p_fake = probabilities[0, 1].item()  # 0.909 (90.9%)
```

**What softmax does:**
```
Logits: [0.45, 3.21]
        ↓
Exponentials: [e^0.45, e^3.21] = [1.57, 24.78]
        ↓
Normalize: [1.57/26.35, 24.78/26.35] = [0.091, 0.909]
        ↓
Probabilities that sum to 1.0
```

---

**Step 7: Make Prediction**
```python
# Threshold at 0.5
is_fake = (p_fake > 0.5)  # True
confidence = max(p_real, p_fake)  # 0.909

# Result
print(f"Prediction: {'FAKE' if is_fake else 'REAL'}")
print(f"Confidence: {confidence:.2%}")

# Output:
# Prediction: FAKE
# Confidence: 90.9%
```

---

**OUTPUT: Detection Result**
```python
{
    'is_fake': True,
    'confidence': 0.909,
    'probabilities': {
        'real': 0.091,
        'fake': 0.909
    }
}
```

---

### Complete CNN Flow Diagram

```
Audio File (suspicious_audio.wav)
    ↓
[librosa.load(sr=16000)]
    ↓
Audio waveform (48000 samples)
    ↓
[Feature Extraction]
    ├─ MFCCs (13 mean + 13 std) = 26 features
    └─ Spectral (centroid, rolloff, bandwidth, ZCR) = 4 features
    ↓

    ↓
[StandardScaler normalization]
    ↓

    ↓
[Reshape: (1, 1, 30)]
    ↓
[CNN Model]
    ├─ Conv Block 1: Extract basic patterns
    ├─ Conv Block 2: Combine patterns
    ├─ Conv Block 3: High-level features
    └─ FC Layers: Final decision
    ↓
Logits [0.45, 3.21]
    ↓
[Softmax]
    ↓
Probabilities [0.091, 0.909]
    ↓
[Threshold at 0.5]
    ↓
FAKE (confidence: 90.9%)
```

## AASIST Detection: Input to Output Flow

### The Question: "How does AASIST process audio differently than CNN?"

### Step-by-Step Process:

**INPUT: Same audio file**
- File: `suspicious_audio.wav`
- Duration: ~3 seconds

---

**Step 1: Load Audio (Same as CNN)**
```python
audio, sr = librosa.load('suspicious_audio.wav', sr=16000)
```

---

**Step 2: Compute Mel-Spectrogram**

**Why spectrogram instead of MFCCs?**
- AASIST uses 2D convolutions → needs 2D input
- Spectrograms preserve spatial structure (time × frequency)
- MFCCs are already compressed (lose information)

```python
# Compute mel-spectrogram
mel_spec = librosa.feature.melspectrogram(
    y=audio,
    sr=16000,
    n_fft=512,       # FFT window: 512 samples (32ms at 16kHz)
    hop_length=256,  # Step: 256 samples (16ms)
    n_mels=64        # 64 mel-frequency bins
)
# Shape: (64, time_frames)
# Example: (64, 187) for 3-second audio

# Convert power to decibels (log scale)
mel_spec_db = librosa.power_to_db(mel_spec, ref=np.max)
# Shape: (64, 187)
```

**What this captures:**
```
Spectrogram = 2D image where:
- X-axis: Time (187 frames)
- Y-axis: Frequency (64 mel bins)
- Color: Energy (in dB)

Looks like:
    Time →
  F ┌─────────────┐
  r │█░░░░█░░░░░░│  ← High frequencies
  e │█░░░░█░░░░░░│
  q │██░░██░░░░░░│  ← Mid frequencies (formants)
  ↓ │████████░░░░│  ← Low frequencies (fundamental)
    └─────────────┘
```

---

**Step 3: Pad/Truncate to Fixed Length**
```python
target_length = 128  # Fixed width

if mel_spec_db.shape[1] < 128:
    # Pad with zeros on the right
    padding = 128 - mel_spec_db.shape[1]
    mel_spec_db = np.pad(mel_spec_db, ((0, 0), (0, padding)))
elif mel_spec_db.shape[1] > 128:
    # Truncate
    mel_spec_db = mel_spec_db[:, :128]

# Now shape: (64, 128)
```

---

**Step 4: Normalize Per-Sample**
```python
# Compute mean and std for THIS spectrogram
mean = mel_spec_db.mean()
std = mel_spec_db.std()

# Normalize
normalized = (mel_spec_db - mean) / (std + 1e-8)
# Shape: (64, 128)

# Now has mean≈0, std≈1
```

**Why per-sample normalization?**
- Different audio has different volume levels
- This makes model invariant to volume
- Each sample normalized independently

---

**Step 5: Add Channel Dimension**
```python
# Reshape for Conv2D
input_tensor = torch.tensor(normalized, dtype=torch.float32)
input_tensor = input_tensor.unsqueeze(0).unsqueeze(0)
# Shape: (1, 1, 64, 128)
#        ↑  ↑  ↑   ↑
#    batch ch freq time
```

---

**Step 6: Feed to AASIST**
```python
# Load model
model = AASISTModel()
model.load_state_dict(torch.load('aasist_model.pth'))
model.eval()

# Forward pass
with torch.no_grad():
    logits = model(input_tensor)
    # Shape: (1, 2)
```

---

**Step 7: AASIST Internal Processing**

**Stage 1: Spectral Convolution (Local Patterns)**
```python
# Input: (1, 1, 64, 128)

# Conv2D Block 1
x = conv2d_1(x)      # (1, 1, 64, 128) → (1, 32, 64, 128)
x = batch_norm_2d(x)
x = relu(x)
x = conv2d_2(x)      # (1, 32, 64, 128) → (1, 64, 64, 128)
x = batch_norm_2d(x)
x = relu(x)
x = maxpool_2d(x)    # (1, 64, 64, 128) → (1, 64, 32, 64)

# Conv2D Block 2
x = conv2d_3(x)      # (1, 64, 32, 64) → (1, 128, 32, 64)
x = batch_norm_2d(x)
x = relu(x)
x = maxpool_2d(x)    # (1, 128, 32, 64) → (1, 128, 16, 32)

# Now: (1, 128, 16, 32)
```

**What it learns:** Local time-frequency patterns (formant edges, harmonic structures)

---

**Stage 2: Graph Attention (Global Relationships)**
```python
# Reshape to sequence
x = x.view(1, 128, 16*32)  # (1, 128, 512)
x = x.permute(0, 2, 1)     # (1, 512, 128)
#                             ↑    ↑    ↑
#                          batch pos feat

# Multi-head attention (4 heads)
x, attention_weights = multi_head_attention(x, x, x)
# Query, Key, Value all from same sequence (self-attention)

# Shape: (1, 512, 128)
```

**What happens in attention:**

For each of the 512 positions:
1. **Compute Query**: "What am I looking for?"
2. **Compute Keys** (all 512 positions): "What do I contain?"
3. **Compute Similarity**: Query · Keys → Attention weights (512 values)
4. **Apply Softmax**: Normalize to probabilities
5. **Weighted Sum**: Σ(attention_weight × Value)

**Example:** Position at time=50, freq=10 might attend to:
- Position time=100, freq=10 (same frequency, different time) - pitch tracking
- Position time=50, freq=20 (same time, different freq) - harmonic relationship
- Position time=70, freq=15 (nearby) - formant transition

**What it learns:** Long-range dependencies (pitch consistency, formant transitions, harmonic correlations)

---

**Stage 3: Temporal Convolution (Time Dynamics)**
```python
# Reshape back to spatial
x = x.permute(0, 2, 1)  # (1, 128, 512)

# Conv1D over time
x = conv1d_1(x)      # (1, 128, 512) → (1, 256, 512)
x = batch_norm_1d(x)
x = relu(x)
x = conv1d_2(x)      # (1, 256, 512) → (1, 128, 512)
x = batch_norm_1d(x)
x = relu(x)

# Shape: (1, 128, 512)
```

**What it learns:** Temporal evolution (how patterns change over time)

---

**Stage 4: Attention Pooling (Focus on Important Regions)**
```python
# Transpose to (batch, time, features)
x = x.permute(0, 2, 1)  # (1, 512, 128)

# Compute attention weights for each time step
attention_scores = fc_attention(x)  # (1, 512, 1)
attention_weights = softmax(attention_scores, dim=1)

# Weighted sum across time
x = (x * attention_weights).sum(dim=1)  # (1, 128)
```

**What it learns:** Which time regions are most informative for classification

**Example:** Time steps 50-80 might get high attention (suspicious formant pattern there)

---

**Stage 5: Classification**
```python
# Fully connected layers
x = fc1(x)        # (1, 128) → (1, 64)
x = relu(x)
x = dropout(x)    # 30% dropout
x = fc2(x)        # (1, 64) → (1, 32)
x = relu(x)
x = dropout(x)
x = fc3(x)        # (1, 32) → (1, 2)

# Output: logits
# Example: [[-0.8, 4.2]]
```

---

**Step 8: Convert to Probabilities (Same as CNN)**
```python
probabilities = F.softmax(logits, dim=1)
# Example: [[0.05, 0.95]]

p_real = 0.05  # 5%
p_fake = 0.95  # 95%

is_fake = True
confidence = 0.95
```

---

**OUTPUT: Detection Result**
```python
{
    'is_fake': True,
    'confidence': 0.95,
    'probabilities': {
        'real': 0.05,
        'fake': 0.95
    }
}
```

### Interview Answer Template:

**Q: "How does AASIST work differently from CNN?"**

**A:**
> "AASIST processes 2D spectrograms instead of 1D feature vectors, which preserves spatial structure. The flow is:
>
> 1. **Input**: Mel-spectrogram (64×128) from audio
> 2. **Spectral Conv**: 2D convolutions extract local time-frequency patterns
> 3. **Graph Attention**: Multi-head attention (4 heads) relates ANY two positions in the spectrogram - this is the key difference. It can detect that pitch at time 0.5s is unnaturally similar to pitch at time 2.3s, which CNNs would miss due to limited receptive field.
> 4. **Temporal Conv**: 1D convolutions model how patterns evolve over time
> 5. **Attention Pooling**: Learns which time regions are most informative
> 6. **Classification**: Final decision
>
> The attention mechanism provides global receptive field (512 positions) vs CNN's local receptive field (~15 features). This is why AASIST achieves 98.14% vs CNN's 95.74% - it catches long-range TTS artifacts."

## Watermark Detection: Input to Output Flow

### The Question: "How do you detect Perth watermarks?"

### Step-by-Step Process:

**INPUT: Audio file (must be NeuTTS Air generated)**
- File: `fake_audio.wav`
- Sample rate: 24kHz (NeuTTS Air native rate)

---

**Step 1: Load Audio at Native Rate**
```python
import librosa
import numpy as np

# IMPORTANT: Load at 24kHz, not 16kHz!
audio, sr = librosa.load('fake_audio.wav', sr=24000)

# Why 24kHz? Because we need 8-12kHz band
# Nyquist theorem: 24kHz sample rate captures up to 12kHz
```

---

**Step 2: Compute STFT (Short-Time Fourier Transform)**
```python
# Compute STFT
stft_matrix = librosa.stft(
    audio,
    n_fft=2048,      # Window size: 2048 samples (85ms at 24kHz)
    hop_length=512   # Step size: 512 samples (21ms)
)
# Shape: (1025, time_frames)
#         ↑
#    frequency bins (n_fft/2 + 1)

# Convert to power spectrum
power_spectrum = np.abs(stft_matrix) ** 2
# Shape: (1025, time_frames)
```

**What STFT does:**
```
Audio waveform (time domain)
    ↓
[Apply FFT to sliding windows]
    ↓
Complex spectrogram (frequency domain)
```

**Each column = one time window's frequency content**

---

**Step 3: Extract 8-12 kHz Band**
```python
# Frequency resolution
freq_resolution = sr / n_fft  # 24000 / 2048 = 11.72 Hz per bin

# Convert kHz to bin indices
lower_freq = 8000  # 8 kHz
upper_freq = 12000  # 12 kHz

lower_bin = int(lower_freq / freq_resolution)  # 682
upper_bin = int(upper_freq / freq_resolution)  # 1024

# Extract band
watermark_band = power_spectrum[lower_bin:upper_bin, :]
# Shape: (342, time_frames)
#         ↑
#    8-12 kHz range
```

**Why 8-12 kHz?**
- Imperceptible to most humans (high frequencies)
- NeuTTS Air embeds Perth watermark here
- Real speech has little energy in this range

---

**Step 4: Compute 5 Features**

**Feature 1: Energy Ratio (Weight: 0.25)**
```python
# Total energy across all frequencies
total_energy = np.sum(power_spectrum)

# Energy in 8-12 kHz band
watermark_energy = np.sum(watermark_band)

# Ratio
energy_ratio = watermark_energy / total_energy

# Example values:
# Real speech: ~0.05-0.10 (5-10%)
# Fake speech: ~0.15-0.25 (15-25%)

# Normalize to [0, 1]
normalized = (energy_ratio - 0.10) / 0.15
normalized = np.clip(normalized, 0, 1)

# Example: energy_ratio = 0.22
# normalized = (0.22 - 0.10) / 0.15 = 0.80
```

---

**Feature 2: Spectral Flatness (Weight: 0.15)**
```python
# Average spectrum over time
mean_spectrum = np.mean(watermark_band, axis=1)

# Geometric mean
geometric_mean = np.exp(np.mean(np.log(mean_spectrum + 1e-10)))

# Arithmetic mean
arithmetic_mean = np.mean(mean_spectrum)

# Spectral flatness
flatness = geometric_mean / arithmetic_mean

# Example values:
# Flatness ≈ 1: White noise (flat spectrum)
# Flatness ≈ 0: Pure tone (spike in spectrum)
# Real speech: Higher flatness (more noise-like)
# Fake speech: Lower flatness (more tonal, vocoder artifact)

# Normalize (invert because lower = more fake)
normalized = 1 - flatness
normalized = np.clip(normalized, 0, 1)
```

---

**Feature 3: Temporal Variance (Weight: 0.20)**
```python
# Energy per time frame in 8-12 kHz band
energy_per_frame = np.sum(watermark_band, axis=0)

# Coefficient of variation
mean_energy = np.mean(energy_per_frame)
std_energy = np.std(energy_per_frame)
variance_coef = std_energy / (mean_energy + 1e-10)

# Example values:
# Real speech: High variance (irregular)
# Fake speech: Low variance (watermark is constant)

# Normalize (invert because lower = more fake)
normalized = 1 - variance_coef
normalized = np.clip(normalized, 0, 1)
```

---

**Feature 4: Periodicity Score (Weight: 0.20)**
```python
# Compute autocorrelation of energy signal
autocorr = np.correlate(energy_per_frame, energy_per_frame, mode='full')
autocorr = autocorr[len(autocorr)//2:]  # Keep positive lags

# Find max autocorrelation at lags 5-50
periodicity = np.max(autocorr[5:50])

# Example values:
# Real speech: Low periodicity (irregular)
# Fake speech: High periodicity (vocoder creates patterns)

# Normalize
normalized = periodicity / np.max(autocorr)
normalized = np.clip(normalized, 0, 1)
```

---

**Feature 5: Frequency Alignment (Weight: 0.20)**
```python
# Average spectrum over time
mean_spectrum = np.mean(watermark_band, axis=0)

# Find peak frequency
peak_bin = np.argmax(mean_spectrum)
peak_freq = (lower_bin + peak_bin) * freq_resolution

# NeuTTS Air signature: Peak around 9500 Hz
optimal_freq = 9500  # Hz
tolerance = 2500     # Hz

# Distance from optimal
distance = abs(peak_freq - optimal_freq)

# Alignment score
alignment = max(0, 1 - distance / tolerance)

# Example:
# peak_freq = 9200 Hz
# distance = |9200 - 9500| = 300 Hz
# alignment = 1 - 300/2500 = 0.88
```

---

**Step 5: Compute Weighted Confidence**
```python
# Weights (sum to 1.0)
weights = {
    'energy_ratio': 0.25,
    'spectral_flatness': 0.15,
    'temporal_variance': 0.20,
    'periodicity': 0.20,
    'frequency_alignment': 0.20
}

# Feature values (normalized to [0, 1])
features = {
    'energy_ratio': 0.80,
    'spectral_flatness': 0.65,
    'temporal_variance': 0.72,
    'periodicity': 0.85,
    'frequency_alignment': 0.88
}

# Weighted sum
confidence = (
    weights['energy_ratio'] * features['energy_ratio'] +
    weights['spectral_flatness'] * features['spectral_flatness'] +
    weights['temporal_variance'] * features['temporal_variance'] +
    weights['periodicity'] * features['periodicity'] +
    weights['frequency_alignment'] * features['frequency_alignment']
)

# Example calculation:
# 0.25×0.80 + 0.15×0.65 + 0.20×0.72 + 0.20×0.85 + 0.20×0.88
# = 0.20 + 0.098 + 0.144 + 0.17 + 0.176
# = 0.788
```

---

**Step 6: Apply Threshold**
```python
threshold = 0.65

has_watermark = (confidence > threshold)

# Example:
# confidence = 0.788
# 0.788 > 0.65 → True

# Result
print(f"Has watermark: {has_watermark}")
print(f"Confidence: {confidence:.3f}")

# Output:
# Has watermark: True
# Confidence: 0.788
```

---

**OUTPUT: Detection Result**
```python
{
    'has_watermark': True,
    'confidence': 0.788,
    'features': {
        'energy_ratio': 0.80,
        'spectral_flatness': 0.65,
        'temporal_variance': 0.72,
        'periodicity': 0.85,
        'frequency_alignment': 0.88
    }
}
```

### Complete Watermark Detection Flow

```
Audio File (24kHz)
    ↓
[STFT: n_fft=2048, hop=512]
    ↓
Power Spectrum (1025 freq bins × time)
    ↓
[Extract 8-12 kHz band]
    ↓
Watermark Band (342 bins × time)
    ↓
[Compute 5 Features]
    ├─ Energy Ratio (how much energy in 8-12kHz?)

    ↓

    ↓

    ↓

```

**Q: "How does watermark detection work?"**

**A:**
> "Watermark detection analyzes the 8-12kHz frequency band where Perth watermarks are embedded:
>
> 1. **STFT**: Convert audio to frequency domain (2048-sample windows at 24kHz)
> 2. **Extract band**: Isolate 8-12kHz range (342 frequency bins)
> 3. **Compute 5 features**:

>

## Triple-Layer Voting: How Predictions Combine

### The Question: "How do you combine all three detectors?"

### Example Scenario:

**Audio file**: `test_audio.wav`

**Step 1: Run All Three Detectors**

```python
# CNN
cnn_result = run_cnn_detection('test_audio.wav')
# {
#     'is_fake': True,
#     'confidence': 0.88
# }

# AASIST
aasist_result = run_aasist_detection('test_audio.wav')
# {
#     'is_fake': True,
#     'confidence': 0.95
# }

# Watermark
watermark_result = run_watermark_detection('test_audio.wav')
# {
#     'has_watermark': True,
#     'confidence': 0.82
# }
```

---

**Step 2: Create Vote Dictionary**
```python
votes = {
    'cnn': {
        'is_fake': True,
        'confidence': 0.88,
        'weight': 0.35
    },
    'aasist': {
        'is_fake': True,
        'confidence': 0.95,
        'weight': 0.35
    },
    'watermark': {
        'is_fake': True,  # has_watermark → is_fake
        'confidence': 0.82,
        'weight': 0.30
    }
}
```

---

**Step 3: Compute Weighted Scores**
```python
fake_score = 0.0
real_score = 0.0

for detector, vote in votes.items():
    vote_strength = vote['confidence'] * vote['weight']

    if vote['is_fake']:
        fake_score += vote_strength
    else:
        real_score += vote_strength

# Calculations:
# CNN: 0.88 × 0.35 = 0.308 → fake_score
# AASIST: 0.95 × 0.35 = 0.333 → fake_score
# Watermark: 0.82 × 0.30 = 0.246 → fake_score

fake_score = 0.308 + 0.333 + 0.246 = 0.887
real_score = 0.0  # All voted fake

total_weight = 0.35 + 0.35 + 0.30 = 1.0
```

---

**Step 4: Make Final Decision**
```python
# Decision
final_is_fake = (fake_score > real_score)
# 0.887 > 0.0 → True

# Confidence (normalize by total weight)
final_confidence = max(fake_score, real_score) / total_weight
# max(0.887, 0.0) / 1.0 = 0.887
```

---

**Step 5: Determine Agreement**
```python
# Count how many voted fake
fake_count = sum(1 for v in votes.values() if v['is_fake'])
# fake_count = 3

# Agreement level
if fake_count == 0 or fake_count == 3:
    agreement = 'UNANIMOUS'  # All agree
elif fake_count == 2:
    agreement = 'MAJORITY'   # 2 out of 3
else:
    agreement = 'SPLIT'      # 1-1-1 or 2 real

# Result: UNANIMOUS
```

---

**Step 6: Find Winner (Most Confident)**
```python
# Find detector with highest confidence
winner = max(votes.items(), key=lambda x: x[1]['confidence'])
winner_name = winner[0]
winner_confidence = winner[1]['confidence']

# winner_name = 'aasist'
# winner_confidence = 0.95
```

---

**OUTPUT: Final Result**
```python
{
    'is_fake': True,
    'confidence': 0.887,
    'agreement': 'UNANIMOUS',
    'winner': 'aasist',
    'layer_votes': {
        'cnn': {'is_fake': True, 'confidence': 0.88},
        'aasist': {'is_fake': True, 'confidence': 0.95},
        'watermark': {'is_fake': True, 'confidence': 0.82}
    }
}
```

**Scenario 1: Unanimous FAKE**

```python
CNN: fake (0.92), AASIST: fake (0.98), Watermark: fake (0.85)

```

### Interview Answer:

**Q: "How do you combine predictions?"**

**A:**
> "I use weighted soft voting with three layers:
>
> 1. **Get predictions**: Each detector outputs is_fake (boolean) and confidence (0-1)
> 2. **Apply weights**: CNN=35%, AASIST=35%, Watermark=30% (empirically tuned)
> 3. **Compute scores**:
>    - fake_score = Σ(confidence × weight) for detectors that voted fake
>    - real_score = Σ(confidence × weight) for detectors that voted real
> 4. **Make decision**: If fake_score > real_score, classify as FAKE
> 5. **Calculate confidence**: max(fake_score, real_score) / total_weight
> 6. **Track agreement**: UNANIMOUS (all 3 agree), MAJORITY (2 agree), or SPLIT
>
> Example: If CNN says fake (0.88), AASIST says fake (0.95), watermark says fake (0.82):
> fake_score = 0.88×0.35 + 0.95×0.35 + 0.82×0.30 = 0.887
> Result: FAKE with 88.7% confidence, UNANIMOUS agreement.
>
> This provides both the final decision AND explainability (which detector was most confident, how much agreement)."
